Evidence:

- Reference solver implemented in `tools/reference-python/max_pain_reference.py`:
  - Self-contained implementation with zero external dependencies (standard Python library only).
  - Expiry-specific candidate strike payoff evaluator:
    $$Total\_Payoff(K_{eval}) = \sum_{c \in Calls} \max(0, K_{eval} - K_c) \cdot OI_c + \sum_{p \in Puts} \max(0, K_p - K_{eval}) \cdot OI_p$$
  - Selects candidate strike $K_{eval}$ minimizing aggregate holder payoff with deterministic lower-strike tie-breaking.
  - Supports structured typed inputs (`OptionContract`), dictionary mapping, and Deribit JSON snapshot payloads.
  - Full exclusion accounting (`invalid_strike`, `invalid_oi`, `invalid_option_type`, inactive contracts).
- Comprehensive unit test suite in `tools/reference-python/test_max_pain.py`:

  - Verified single-strike straddle ($K=100,000$, $Payoff=0$).
  - Verified symmetric 3-strike chain ($K=100,000$, $Payoff=200,000$).
  - Verified asymmetric call-heavy and put-heavy chains.
  - Verified deterministic tie-breaking selecting lower strike on equal payoff.
  - Verified expiry isolation, zero open interest validity, and invalid input filtering.
  - Verified JSON interoperability and exact parity with TypeScript calculation engine.
