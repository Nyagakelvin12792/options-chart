# M4.9 Performance Benchmark Suite

## Status: COMPLETE

- Owner: Antigravity
- Updated: 2026-08-26
- Scope: Independent performance benchmarking of the mathematical options calculation engine across TypeScript and Python reference runtimes on standard 1,000-contract portfolios.

---

## 1. Overview & Verification Summary

Implemented an automated latency, throughput, and memory benchmarking harness in [`scripts/benchmark-options-engine.mts`](../../scripts/benchmark-options-engine.mts) and integrated unit tests in [`packages/options-engine/src/benchmark.test.ts`](../../packages/options-engine/src/benchmark.test.ts).

The benchmark evaluates the end-to-end options calculation pipeline across:

- **1,000 active contracts** across 10 expiry terms (1D to 365D) and 50 strikes ($50,000 to $100,000).
- Full 121-point Gamma Profile ($0.70\times S$ to $1.30\times S$).
- Two-pass fine spot grid Gamma Flip refinement.
- Call Wall and Put Wall selection.
- Max Pain expiry solver.
- Aggregate metrics and OI-weighted average IV.
