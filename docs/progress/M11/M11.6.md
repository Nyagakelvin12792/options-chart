## Objective

Introduce a default-off, read-only provider boundary after the corrected M11.5
deterministic baseline. JEV may classify a compact `DecisionContextV1`, and a
general-purpose provider may narrate only the already converged decision. Neither
provider can calculate prices or risk, override deterministic prohibitions, alter
chart state, or initiate execution.

## Checkpoint 1 Delivered

- Added a provider-neutral runner with bounded timeout, external cancellation,
  runtime schema validation, context and provider identity checks, stale-result
  rejection, and immutable content-hashed audit records.
- Added a server-oriented JEV REST adapter for the typed SystemOne endpoint. Its
  request contains one closed-choice question over compact categorical state and
  excludes raw ticks, books, chains, numeric evidence, balances, and credentials.
- Recorded the validated decision distribution, confidence, returned model
  version, latency, reason codes, and fail-closed error status.
- Added a post-convergence narration contract containing IDs, classifications,
  reasons, warnings, health states, and evidence-version provenance only.
- Added structured narration output for thesis, evidence, conflict, trigger,
  invalidation, and no-trade reasons.
- Added content-aware caching, explicit regeneration, timeout and cancellation,
  generation-based stale rejection, superseded-request abortion, and visible
  source/generation timestamps.
- Kept every provider default-off. No route, browser integration, dashboard
  behavior, chart state, risk authority, exchange credential, or execution path
  changed.
