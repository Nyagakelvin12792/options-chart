# M11.2 Cryptofeed Shadow Collector

Status: BLOCKED - LINUX LIVE OBSERVATION PENDING
Date: 2026-10-15

## Objective

Create a zero-cost local shadow collector for validated Binance BTCUSDT Spot
trades and L2 events without changing any production feed or calculation.

## Scope

- `MarketEventV1` TypeScript schema and generated JSON Schema.
- Cryptofeed adapter for Binance Spot BTCUSDT trades and L2 book updates.
- Event identity, timestamps, sequence metadata, and provenance.
- Duplicate, gap, stale, reconnect, and unsupported-channel health reporting.
- Rotating append-only NDJSON storage and deterministic replay reader.
- Shared Python and TypeScript fixtures and schema-parity tests.

## Explicitly Excluded

- CVD and absorption calculations.
- JEV and LLM dependencies.
- Dashboard UI changes.
- Vercel deployment changes.
- Binance candle or Deribit options replacement.
- Live orders or private exchange credentials.

## Exit Evidence

- Focused Python and TypeScript tests.
- Deterministic replay hash for a recorded fixture.
- Bounded live-session health report.
- Gap, stale, duplicate, and reconnect test evidence.
- Full repository typecheck, lint, test, build, and progress-policy results.

## Implemented

- Canonical TypeScript contracts with generated checked Python-service schemas.
- Strict Python deserialization aligned with the TypeScript event envelope.
- Cryptofeed trade and L2 normalization with receipt-time provenance.
- Deterministic UTF-8 event identity and exact SQLite-backed deduplication.
- Thread-safe rotating NDJSON storage with restart and corrupt-tail recovery.
- Deterministic replay with receipt-time cutoff and strict archive-prefix isolation.
- Startup stale, collector-error, unsupported-channel, and observability health records.
- Joined stale-monitor shutdown before the writer is closed.
